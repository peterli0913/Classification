1 · Base model · methods

Four estimators, one comparison table

XGBoost

Strong small-n baseline. Feature importances are the first thing a chemist can argue with.

Descriptor attention

Each group is a token. Self-attention returns group weights. Weaker fit, used for explanation.

SMILES + descriptor hybrid

BiGRU over characters + the 17-D vector. Tests whether structure adds anything beyond Kraken descriptors.

Ensemble average

Mean of the three. More stable than attention alone; does not beat XGBoost on this split.

3 · Interactive prediction

What the live box actually does

Input

SMILES + 17 comma-separated descriptors, same order as the training columns.

sterimol_L, B1, B5, burL, burB1, burB5, vbur…, nmr_P, fmo_μ, fmo_η, nbo, vmin, E_solv, …

Output

Four numbers: XGBoost, attention, SMILES hybrid, ensemble average — plus the four group weights as a bar chart.

Demo move

Click Load sample (first Kraken row) → Run prediction. Then say: “this is a buried-volume-ratio prior, not a Buchwald yield.” Switch to the BO panel for yield.

API on the dashboard: POST /api/predict

5 · Talk track

What to say, in this order

Bottom line: we run two tracks in one interface — base interpretation, and RDKit/PyG true-yield modeling.

Base track is stable. The features a chemist should argue with first are sterimol_B1 (0.260), E_solv_total (0.185), and sterimol_B5 (0.118).

The yield track uses Murcko scaffold checks. Mean scaffold RMSE is about 14.2 yield points, not the random-split 7.8.

For a next wet-lab shortlist, take the EI table — starting with tBuXPhos / AdBrettPhos × 4-ethyl-iodobenzene × MTBD — then look at the uncertainty column, not only the mean.
